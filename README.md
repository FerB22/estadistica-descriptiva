## Convención estándar para nombrar archivos (SemVer simplificado)

Para evitar sobrescrituras accidentales y saber siempre cuál es el archivo vigente, se adopta este esquema:

`[Nombre_Proyecto]_[Modulo]_[Version]_[Estado/Iniciales].[ext]`

### Ejemplos prácticos para los trabajos

#### Durante el avance:
- `Trabajo1_Estadistica_v1.0.ipynb` (primera versión completa).
- `Trabajo1_Estadistica_v1.1_FB.ipynb` (versión con las adiciones editadas).
- `Trabajo1_Estadistica_v1.2_P3_Corregida.ipynb`.

#### Para la entrega final:
- `Trabajo1_Estadistica_v2.0_FINAL_ENTREGA.ipynb`.

- `Presentacion_Estadistica_v1.1_Revision.pdf`
